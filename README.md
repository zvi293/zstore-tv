# Zstore TV 2.0
A personal room screen for Samsung Tizen TVs, as a [TizenBrew](https://github.com/reisxd/TizenBrew) app module.

- Live-sky home screen (real sunrise/sunset, clouds, rain, stars), clock, Hebrew date, weather, zmanim, parasha, holidays
- One-click ad-free YouTube (launches the TizenTube module)
- Scenes: generative gallery, aquarium, fireplace, aurora, space warp, sleep rain
- Room: morning sunrise + daily brief, lofi focus (generative music), 4-7-8 breathing, quiet clock, holiday countdown + Hanukkah menorah, Shabbat screen, trivia

Add in TizenBrew: Module Manager -> Add -> GitHub -> `zvi293/zstore-tv`
